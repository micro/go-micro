---
title: "v7 direction"
---

Go Micro focuses on services and agents. Services expose typed capabilities;
agents use those capabilities to carry out work.

The standalone flow package and its CLI commands have been removed. Agent
execution records, checkpoints, approvals and resume remain in `agent` and
`agent/run`. Existing agent checkpoints retain their storage format.

The next work is to make service discovery, agent execution, cancellation,
errors and inspection consistent across Go APIs, the CLI and gateways. Keep
interfaces small and prove changes through running applications.
